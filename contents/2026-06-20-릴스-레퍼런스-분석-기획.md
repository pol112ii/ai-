## 📊 요즘 잘 되는 릴스 공식 (트렌드 요약)
1. **첫 1초 후킹이 전부.** 비슷한 오프닝/반복 후킹이 통한다는 건, 시작에 '결과 먼저' 또는 '질문' 박는 게 정답.
2. **템플릿형이 유리.** 특정 BGM에 맞춰 클립 전환 / 텍스트 오버레이 정보형 포맷이 알고리즘 선호.
3. **자막은 기본, 키워드는 브랜드 폰트로 강조.** AI 자동자막 깔되 핵심 단어만 톤앤매너 폰트로.
4. **트렌디 오디오(리믹스·장르혼합)** 올라타면 노출 ↑.
5. **DIY는 ASMR·비포애프터가 강함.** 손으로 만드는 소리·과정·완성 대비가 숏폼에서 시선 강탈.

## ✍️ 바로 찍는 릴스 대본 3종 (장면 단위)

### 🎥 릴스 A — 「비포→애프터 + ASMR」 (개인 타깃, 15초)
- **0~1초(후킹):** 완성된 바다 텀블러 클로즈업 + 자막 **"이거 제가 만든 거예요👀"**
- **2~5초:** 밋밋한 흰 컵 보여주기 → 도안 가위로 콕콕 (가위질 소리 ASMR)
- **6~10초:** 미지근한 물에 챱! 담그기 → 살살 미는 손 클로즈업 (물소리 강조)
- **11~14초:** 완성! 회전샷 + 자막 **"가위랑 물만 있으면 끝🌊"**
- **15초(CTA):** **"링크 콕! @joyfulmoments_kr"**
- 🎵 잔잔한 트렌디 로파이 / 자막 핵심어만 브랜드 컬러

### 🎥 릴스 B — 「단체 워크숍 정보형」 (B2B, 12초)
- **0~1초(후킹):** 텍스트만 **"여름 사내 워크숍 뭐하지?🏢"** (검은 화면 → 키트 등장)
- **2~7초:** 여러 명이 동시에 텀블러 만드는 장면 빠른 컷 + 오버레이
  - "준비물 0개 ✅" / "1인 16,000원대 ✅" / "강사 없이 QR가이드 ✅"
- **8~11초:** 완성품 다 같이 들고 단체샷 + **"로고 커스텀 OK (100개↑ 셋업비 지원)"**
- **12초(CTA):** **"단체 견적 = 프로필 DM 📩"**
- 🎵 경쾌·밝은 BGM

### 🎥 릴스 C — 「똥손 챌린지 + 반전」 (참여 유도, 10초)
- **0~1초:** 손 떨면서 도안 드는 모습 + 자막 **"저 진짜 똥손인데요…😰"**
- **2~6초:** 콕콕(펀치니들) / 챱챱(물전사) 과정 빠르게
- **7~9초:** 완성품 짠! + 자막 **"…금손이 됐습니다😎"**
- **10초(CTA):** **"#똥손도금손챌린지 인증하면 커피 쏨☕"**
- 🎵 반전용 비트드랍 오디오

## 💡 제작 팁 (똥손 사장님도 OK)
- 삼각대 하나 + 폰 고정, 위에서 내려찍는 **탑뷰** 각도면 과정샷 충분.
- 소리(가위·물·문지르기)는 **마이크 가까이** → ASMR 효과는 음질이 8할.
- 한 번 찍어두면 A/B/C가 **같은 클립 재편집**으로 다 나와요. (가성비 촬영)
